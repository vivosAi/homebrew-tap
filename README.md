# vivosAi/tap

Homebrew tap for [Nimbus](https://github.com/vivosAi/nimbus) — a macOS menu bar
utility that draws an animated ring of light around the window with keyboard
focus.

```sh
brew install --cask vivosAi/tap/nimbus
```

To update later:

```sh
brew upgrade --cask nimbus
```

The cask points at the signed and notarised disk image published on the
[Nimbus releases page](https://github.com/vivosAi/nimbus/releases).
